# 🏠 House Price Prediction

This project builds a machine learning model to predict house prices using various features such as area, location, number of rooms, etc. The dataset is processed and trained using regression models.

## 📚 Project Structure

- **Data Cleaning & Preprocessing**: Handles missing values, feature encoding, and normalization.
- **Modeling**: Uses regression models like Linear Regression, Decision Tree, or Random Forest for predicting house prices.
- **Evaluation**: Assesses model performance using metrics such as Mean Squared Error (MSE) and R² Score.
